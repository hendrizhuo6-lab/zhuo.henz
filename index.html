INFO

Tentang Aplikasi

Domain Ops Console v3.1 adalah dashboard operasional domain untuk tim network intelligence.

Modul

  • Filter — Cek pergantian domain dengan validasi brand & tipe
  • Filter Domain — Kelompokkan domain berdasarkan brand otomatis
  • DNS Parser — Pisahkan domain dan nameserver dari data mentah
  • Redirect — Pratinjau dengan loading & error handling, buka, dan ekspor daftar tautan
  • Server Map — Pemetaan otomatis server, brand, dan fallback IDN

Teknologi

  • Vanilla JavaScript (ES6+)
  • CSS Custom Properties & Grid
  • Clipboard API + fallback
  • WAI-ARIA accessibility
HELP

Panduan Penggunaan

Keyboard Shortcuts

  • ⌘+1 s/d 5 — Pindah modul
  • ⌘+K — Command palette
  • ⌘+↵ — Jalankan aksi utama modul aktif
  • ↑/↓ — Navigasi sel DNS saat fokus di tabel
  • Ctrl+C — Salin sel/domain yang sedang difokuskan
  • Esc — Tutup command palette

Alur Kerja

  1. Pilih modul dari sidebar (atau shortcut)
  2. Tempel data di panel input kiri
  3. Klik tombol aksi utama (atau ⌘↵)
  4. Hasil muncul di panel kanan / bawah
  5. Gunakan tombol copy/ekspor untuk mengambil hasil

Tips Redirect Preview

  • Pilih domain untuk membukanya di jendela WebView2 terpisah pada aplikasi desktop
  • Tombol ↻ memuat ulang halaman di jendela WebView2
  • Tombol ↗ membuka kembali domain di jendela WebView2
  • Jika host tidak merespons, halaman menampilkan pesan error dan opsi untuk mencoba lagi

Tips Umum

  • Gunakan kolom pencarian di sidebar untuk menemukan modul dengan cepat
  • Klik domain di tabel untuk focus & copy dengan Ctrl+C
  • Gunakan notifikasi untuk melihat hasil aksi proses dan salin
