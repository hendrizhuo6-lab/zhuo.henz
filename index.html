ℹ️ Tentang Aplikasi

Domain Ops Console v2.0 adalah alat manajemen domain yang dirancang untuk tim operasional.

Fitur Utama:

  • 🔍 Cek Pergantian Domain - Bandingkan data lama dan baru dengan validasi otomatis
  • 🗂 Filter Domain - Kelompokkan domain berdasarkan brand dengan auto-detection
  • 📊 DNS Parser - Pisahkan domain dan nameserver dari data mentah
  • 🌐 Server & Brand Mapping - Pemetaan otomatis server, brand, dan fallback IDN

Teknologi:

  • Vanilla JavaScript (ES6+)
  • CSS Custom Properties untuk theming
  • Clipboard API dengan fallback
  • ARIA accessibility support

◎ Bantuan & Panduan

📖 Cara Penggunaan

1. Cek Pergantian Domain

  1. Masukkan data lama di kolom kiri dengan format: [BRAND] diikuti daftar domain
  2. Masukkan data baru di kolom kanan dengan format yang sama
  3. Klik CEK PERGANTIAN untuk membandingkan

2. Filter Domain

  1. Tempelkan daftar domain di kolom kiri (satu per baris)
  2. Hasil pengelompokan otomatis muncul di kolom kanan

3. DNS Parser

  1. Tempelkan data mentah (domain + nameserver) di kolom kiri
  2. Klik Proses untuk memisahkan data

4. Server & Brand Mapping

  1. Tempelkan daftar brand atau domain mentah pada tab Server Mapping
  2. Klik Proses Mapping
  3. Lihat hasil pemetaan di Kotak 1 (Terdeteksi) dan Kotak 2 (Fallback IDN)
